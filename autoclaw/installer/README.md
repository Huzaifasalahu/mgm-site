# AutoClaw - User Manual

## Welcome to AutoClaw!

AutoClaw is your autonomous AI agent that can automate tasks on your computer.

## Quick Start

### First Launch
1. Run AutoClaw from Start Menu (Windows) or Applications (macOS)
2. Go to Settings tab
3. Enter your LLM API key (OpenAI, Anthropic, etc.)
4. Click "Save Configuration"

### Your First Task
1. Go to Chat tab
2. Type a goal like: "Search for Python tutorials and save them to my documents"
3. Press Enter or click Execute
4. Watch AutoClaw work!

## Features

### 💬 Chat
Natural language interface for giving goals to your agent.

### 🛠️ Skills
Pre-loaded capabilities:
- **Browser Automation**: Control web browsers, fill forms, extract data
- **File Manager**: Read, write, organize files
- **Content Creator**: Generate reports, articles, social posts
- **System Control**: Launch apps, run commands, screenshots
- **Data Analyzer**: Process CSV, JSON, create charts
- **Messenger**: Send messages via Slack, Telegram, Feishu
- **Web Search**: Search Google, Bing
- **Memory**: Persistent learning across sessions
- **Scheduler**: Automate recurring tasks

### 📅 Scheduler
Schedule tasks to run automatically:
- One-time: Run at specific date/time
- Interval: Run every X minutes
- Daily: Run at same time every day
- Weekly: Run on specific weekday

### 🧠 Memory
AutoClaw learns from your tasks:
- Stores successful task executions
- Remembers your preferences
- Improves over time

### ⚙️ Settings
Configure:
- LLM provider and API keys
- Messaging integrations
- Browser profiles
- System preferences

## Example Tasks

Try these examples:
- "Create a weekly report from my sales data CSV"
- "Search for news about AI and send summary to Slack"
- "Take a screenshot every hour and save to Documents"
- "Download all images from this webpage"
- "Fill out this form with my information"

## Tips

1. **Be Specific**: Clear goals get better results
2. **Start Small**: Begin with simple tasks
3. **Monitor Progress**: Watch the chat for updates
4. **Review Memory**: Check what AutoClaw has learned
5. **Schedule Wisely**: Don't overload with too many tasks

## Safety

⚠️ **Important**: AutoClaw can control your computer. Always:
- Review tasks before execution
- Keep backups of important data
- Don't grant unnecessary permissions
- Monitor automated tasks
